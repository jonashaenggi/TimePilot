# TimePilot Web

Die Web-App zu TimePilot. Installation, Funktionen und Datenhaltung sind im [Projekt-README](../README.md) beschrieben.

Lokale Entwicklung: `pnpm dev`. Prüfungen: `pnpm test` und `pnpm exec tsc --noEmit`. Produktions-Build: `pnpm build`.

Die Datei `.openai/hosting.json` enthält die Kennung der privaten Sites-Veröffentlichung. Sie enthält keine Zugangsdaten. Generierte Ausgaben, lokale Laufzeitdateien und persönliche Backups gehören nicht ins Repository.
